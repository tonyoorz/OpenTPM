# BMW 缺陷数据库查询指南

## 何时触发

当用户询问以下内容时,使用此 skill:

- BMW 缺陷查询、缺陷编号、召回信息
- 缺陷严重等级、处理状态
- 如何使用缺陷数据库 MCP 工具

## 缺陷字段说明

| 字段 | 说明 |
|---|---|
| 缺陷编号 | 唯一标识,格式为 `DEF-YYYY-NNNNN` |
| 严重等级 | S1(最高)至 S4(最低) |
| 状态 | `open` / `in_progress` / `resolved` / `closed` |
| 车型 | 受影响的 BMW 车型代码 |
| 召回状态 | `recall` / `service_action` / `monitoring` |

## 查询流程

1. 用户提供缺陷编号或关键词
2. 调用缺陷数据库 MCP 工具查询
3. 返回结果时按严重等级排序(S1 优先)
4. 如有召回信息,优先展示

## 注意事项

- 缺陷数据仅供内部参考,不对外公开
- S1/S2 级别缺陷需提示用户关注时效性
- 查询无结果时建议用户检查编号格式或扩大搜索范围
